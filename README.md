# 3D Printing Notes: Resin, Lattices and Elastomer Parts

**English** | [中文](#中文)

Plain-language notes on how flexible 3D printed parts are made, with a focus on resin (DLP) printing and lattice structures of the kind used in printed footwear, insoles and cushioning. Written for makers, students and designers; not tied to any one printer or brand.
