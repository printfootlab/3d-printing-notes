# 术语表

[English](../en/glossary.md) | **中文**

## 工艺

| 术语 | 英文 | 解释 |
|---|---|---|
| SLA（立体光刻） | Stereolithography | 用激光描出并固化每一层的树脂打印 |
| DLP（数字光处理） | Digital light processing | 用投影仪一次固化整层的树脂打印 |
| LCD / MSLA | LCD / masked SLA | 用 LCD 屏作遮罩、一次曝光整层的树脂打印 |
| CLIP / DLS | Continuous printing | 用透氧窗口的连续树脂打印，零件连续上拉，不用每层单独剥离 |
| FDM（熔融沉积成型） | Fused deposition modelling | 把熔化的塑料丝从喷嘴挤出来打印 |
| SLS / MJF | Powder-bed fusion | 粉末床工艺：用激光（SLS）或熔融剂加热（MJF）把一层层塑料粉末熔合 |
| 成型平台 | Build platform | 零件打印在上面的平板；自下而上的树脂打印机中，它随零件长高而从料槽里升起 |
| 支撑 | Supports | 托住悬空部分、固定零件的临时结构，打印后去除 |

## 材料

| 术语 | 英文 | 解释 |
|---|---|---|
| 弹性体 | Elastomer | 能大幅拉伸或压缩、并恢复原状的高分子材料 |
| 光引发剂 | Photoinitiator | 树脂中吸收光、启动固化反应的成分 |
| 生坯 | Green part | 刚打印出来的树脂件：已成型，但还没完全固化 |
| 二次固化 | Post-cure | 用光和/或热处理清洗后的零件，使其达到最终强度 |
| 双重固化树脂 | Dual-cure resin | 打印时用光定形，再经第二次（通常是加热）固化达到最终性能的树脂 |
| 热塑性材料 | Thermoplastic | 加热会软化、可以重新熔化的高分子，如 TPU |
| 热固性材料 | Thermoset | 固化后形成永久交联网络、不能再熔化的高分子，如固化后的树脂 |
| TPU（热塑性聚氨酯） | Thermoplastic polyurethane | 柔性热塑性材料，有线材和粉末两种形式，用于打印弹性件 |
| 邵氏 A / 邵氏 D | Shore A / Shore D | 硬度计的两种标尺：邵氏 A 用于较软的材料，邵氏 D 用于较硬的材料 |
| 压缩永久变形 | Compression set | 材料被压住一段时间后无法恢复的比例；对缓冲件来说越低越好 |

## 晶格与文件

| 术语 | 英文 | 解释 |
|---|---|---|
| 晶格 | Lattice | 由杆或壁组成的单元在空间里重复排列形成的结构 |
| 单元 | Unit cell | 晶格中最小的重复单位 |
| 杆 | Strut | 晶格中的一根细梁 |
| 节点 | Node | 杆与杆相交的点，裂纹常从这里开始 |
| 相对密度 | Relative density | 晶格体积中实心材料所占的比例 |
| 弯曲主导晶格 | Bending-dominated lattice | 受力时杆主要弯曲的晶格；同样密度下比拉伸主导晶格更软 |
| TPMS（三周期极小曲面） | Triply periodic minimal surface | 在三个方向上重复的光滑曲面家族，包括 gyroid、Schwarz P、Schwarz D |
| Gyroid（螺旋二十四面体曲面） | Gyroid | 一种 TPMS 晶格，壁面光滑、通道开放，受力均匀、容易排液 |
| Voronoi 晶格 | Voronoi lattice | 由散布的点生成不规则单元的晶格，便于让单元尺寸逐渐变化 |
| STL | STL | 常用的 3D 文件格式，只用三角面片记录表面 |
| 3MF | 3MF | 更紧凑的 3D 打印文件格式，还能记录单位、材料等信息 |
