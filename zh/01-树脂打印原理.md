# 树脂 3D 打印的原理

[English](../en/01-how-resin-printing-works.md) | **中文**

树脂打印，也叫光固化（vat photopolymerization），是用光照让液态树脂一层层变硬、堆出零件。每一层都是零件的一个薄切片，固化在上一层之上。几种主要工艺的区别在于光是怎么照上去的。

> **要点**
> - 树脂打印用光把液态树脂一层层固化成零件。
> - SLA 用激光逐点扫描；DLP 和 LCD 一次曝光整层；连续打印（CLIP / DLS）省去了每层单独的剥离步骤。
> - 层厚、曝光、像素大小、支撑和摆放方向决定打印质量。
> - 整层曝光让树脂打印特别适合做细密的晶格。

---

## 四种常见的光源方式

| 工艺 | 每层怎么曝光 | 说明 |
|---|---|---|
| SLA（立体光刻） | 激光逐点描出这一层 | 最早的工艺；面积越大，每层用时越长 |
| DLP（数字光处理） | 投影仪一次照亮整层 | 每层用时和这一层填了多少无关 |
| LCD / MSLA | LCD 屏遮挡光源，一次曝光整层 | 和 DLP 类似，桌面打印机常用 |
| 连续打印（如 CLIP / DLS） | 投影仪透过透氧窗口曝光，零件可以连续上拉，不用一层层剥离 | 更快、层纹更少；很多量产弹性体零件用这种方式 |

DLP 和 LCD 都是“整层曝光”。对晶格来说这一点很关键：晶格的每一层都由很多分散的小块组成，激光要一个个去扫，投影仪一次就能全部固化。

## 打印过程

1. **切片**：软件把 3D 模型切成很多层，每层通常只有几十微米厚，再把每层转成一张图像。
2. **曝光**：成型平台下降到料槽底部附近，中间留出一层树脂。光从透明的槽底照上来，把这层树脂固化在平台上。
3. **剥离**：平台抬起，把刚固化的一层从槽底剥下来，新的树脂流进下方。
4. **重复**，直到零件完成。零件是倒挂在平台上的。

大多数桌面打印机和很多工业打印机都是这种“自下而上”的方式。每层从槽底剥离时会拉扯零件，这也是支撑和摆放方向很重要的原因之一。

## 影响质量的因素

| 因素 | 影响 |
|---|---|
| 层厚 | 层越薄，侧面越光滑、细节越好，但打印更慢 |
| 曝光时间 | 太短，细小结构长不出来或会脱落；太长，光会溢出边缘，小孔和缝隙被填死。晶格过曝时会出现部分孔被堵住 |
| 像素大小（XY 分辨率） | 决定能打出的最细的杆和最小的缝。只有几个像素宽的杆很脆弱，不一定能稳定打出来 |
| 支撑 | 悬空部分和最初几层需要支撑来抵抗剥离力。晶格常常能部分自支撑，因为每个单元会托住上一个单元 |
| 摆放方向 | 倾斜摆放会改变支撑的位置、每层面积和层纹位置。平放的鞋垫每层面积很大、剥离力大；竖放则每层小，但打印高度大 |

## 为什么树脂适合做细密晶格

树脂打印能做出细小、光滑的结构，所以能做出其他方法难以实现的小孔、细杆晶格。

- **FDM（熔融挤出）**：受喷嘴宽度和杆与杆之间架桥能力的限制。
- **SLS、MJF（粉末床）**：也能做细密晶格，但每个孔里没烧结的粉末都要清出来。
- **树脂打印**：也有自己的清理难题，就是困在晶格里的液态树脂，见 [04 树脂件后处理](04-树脂件后处理.md)。
