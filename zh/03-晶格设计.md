# 3D 打印的晶格设计

[English](../en/03-designing-lattices.md) | **中文**

晶格是把一个小单元在空间里重复排列形成的结构。用同样的材料，晶格可以让零件比实心件更轻、更软、更透气。

> **要点**
> - 晶格由单元重复而成；单元尺寸、杆粗和相对密度决定它的性能。
> - 杆状单元简单；面状的 TPMS 单元（如 gyroid）受力更均匀、排液更好。
> - 渐变、随形和 Voronoi 晶格能让同一个零件这里硬、那里软。
> - 孔要开放、互相连通，树脂才能排出来。

---

## 单元

重复的那一小块叫**单元**（unit cell），用三个量描述：

| 参数 | 含义 |
|---|---|
| 单元尺寸 | 一个单元的宽度 |
| 杆粗或壁厚 | 单元里材料有多厚 |
| 相对密度 | 单元体积中实心部分的比例。杆越粗或单元越小，相对密度越高 |

材料相同时，相对密度和单元类型决定了大部分力学表现。

## 两类单元

**杆状（梁）晶格**由直杆在节点处连接而成，比如立方、体心立方、八面体桁架（octet）、蜂窝类单元。容易描述，也容易检查。按杆的排布方式分两种：

| 类型 | 受力方式 | 表现 |
|---|---|---|
| 弯曲主导 | 杆受力时主要弯曲 | 更软，缓冲感强 |
| 拉伸主导 | 杆主要沿长度方向受拉或受压 | 更硬、更结实 |

缓冲类零件通常用弯曲主导的单元。

**面状晶格**由光滑、连续的曲面组成。最常见的是 **TPMS**（三周期极小曲面），比如 gyroid、Schwarz P、Schwarz D（金刚石型）。它们没有尖锐的节点，应力分布更均匀；内部通道全部连通，有利于排出树脂和空气流通。

## 用方程表示 gyroid

TPMS 晶格通常由公式生成，而不是手工画出来。gyroid 可以近似表示为：

```
sin(x)·cos(y) + sin(y)·cos(z) + sin(z)·cos(x) = 0
```

表达式等于零的点构成曲面。要得到能打印的壁，软件保留表达式落在 −t 到 +t 之间的所有点，t 越大壁越厚；缩放 x、y、z 就能改变单元尺寸。

## 渐变、随形和 Voronoi 晶格

实际零件很少整块用同一种均匀晶格：

| 类型 | 做法 |
|---|---|
| 渐变晶格 | 单元尺寸或厚度逐渐变化，比如脚跟下更硬、足弓下更软 |
| 随形晶格 | 让单元网格顺着曲面弯曲，表面的单元不会被生硬地切断 |
| Voronoi（随机）晶格 | 用散布的点生成不规则单元，改变点的疏密就能方便地做出渐变 |

## 从设计到可打印文件

晶格里有大量细小结构，传统 CAD 处理起来很吃力：

| 方式 / 格式 | 说明 |
|---|---|
| 隐式建模 | 把晶格描述成数学场（如上面的 gyroid 方程），最后一步才转成网格。很多专业晶格软件用这种方式 |
| STL | 只存三角面片。一整块晶格鞋垫的 STL 文件可能非常大 |
| 3MF | 较新的格式，更紧凑，能携带更多零件信息 |

## 设计检查清单

- **最小特征尺寸**：杆和壁要足够粗，既要符合打印机分辨率，也要经得住清洗。
- **孔开放且连通**：封闭的空腔会困住液态树脂（或未烧结的粉末），清不出来。
- **排液路径**：树脂打印时，每个单元都要有让树脂流出去的路径，见 [04 树脂件后处理](04-树脂件后处理.md)。
- **表皮和边缘**：晶格外表面加一层薄的实心皮，边缘会更光滑结实，但那里就不透气、不排水了。
